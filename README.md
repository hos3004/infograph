# Infographic Video Generator — Desktop V2

أداة سطح مكتب داخلية (Electron + Remotion) لإنتاج فيديوهات إنفوجرافيك تلفزيونية بجودة 1920×1080 بدون الحاجة لبرامج مونتاج. مدعومة بـ Gemini AI لتوليد المحتوى والتعليق الصوتي.

---

## المتطلبات

| المتطلب | الوصف |
|---------|-------|
| Node.js | نسخة LTS حديثة (18+) |
| مفتاح Gemini API | مطلوب لتوليد المحتوى والصوت (يُضاف من الإعدادات ⚙️) |

---

## هيكل الأصول (Assets)

ضع الملفات في المجلدات التالية داخل `desktop-v2/assets/`:

```
desktop-v2/assets/
├── overlays/     ← ملفات .mov أو .png شفافة (طبقات بصرية)
├── music/        ← ملفات .mp3 (موسيقى خلفية)
├── endpage/      ← ملف .mp4 واحد (شاشة الخاتمة)
└── fonts/        ← rb.ttf (خط العرض الرئيسي)
```

---

## تشغيل التطبيق

```bash
# تثبيت الحزم (مرة واحدة)
npm install

# تشغيل تطبيق سطح المكتب
npm run desktop:v2
```

الفيديوهات الناتجة تُحفظ في:
`%APPDATA%\InfographicGeneratorDesktopV2\output\Video_XXXX.mp4`

## التبويبات (Tabs)

### 1. الشرائح
- رفع صور أو مقاطع فيديو للشرائح عبر زر "إرفاق شرائح"
- تعديل النص لكل شريحة مباشرةً من القائمة
- توليد تعليق صوتي لكل شريحة منفردةً (زر 🎙 بجوار كل شريحة)
- كتم صوت شريحة محددة (زر 🔇)
- إعادة ترتيب الشرائح بالسحب والإفلات

### 2. النصوص
| الإعداد | الوصف |
|---------|-------|
| موضع النص من الأسفل | تحريك كتلة النص عمودياً (40–280 px) |
| موضع النص أفقياً | تحريك كتلة النص يميناً/يساراً (−30% إلى +30%) |
| حجم الخط | 24–96 px |
| حركة دخول النص | 15 نمط انيميشن مختلف |
| عمق سينمائي | تأثير باراكس بعد ظهور النص |
| لون شريط النص | خمسة ألوان (برتقالي، أحمر، أزرق، ذهبي، داكن) |
| سُمك الإطار السينمائي | حجم الشريط الأسود العلوي/السفلي |

**تنسيق النص:** يمكن استخدام `++` لتقسيم السطور إلى أجزاء (كيكر ++ عنوان ++ شرح ++ خلاصة)، و`** **` لتحديد كلمة بطلة.

### 3. الصوتيات
- **توليد تعليق صوتي:** اكتب نصاً وانقر "توليد تعليق صوتي" → يُنتج ملف WAV للفيديو كله
- **إرفاق ملف:** استيراد ملف صوتي خارجي
- **مستوى التعليق:** تحكم في مستوى الصوت (0–100%)
- **الموسيقى:** اختر من الأصول المتاحة + تحكم في المستوى

### 4. محتوى (AI)
توليد كامل للمحتوى بالذكاء الاصطناعي:

**القسم أ — إعدادات التوليد:**
- موضوع أو مقالة للتحويل إلى شرائح
- عدد الشرائح (3–30)
- أسلوب المحتوى: وثائقي / إخباري / قانوني / اقتصادي / اجتماعي / سوشيال ميديا
- نمط النص المفضل

**القسم ب — السكريبت الصوتي:**
- بعد التوليد تظهر السكريبت الكاملة (15–18 كلمة لكل شريحة ≈ 8 ثواني)
- قابلة للتعديل قبل التوليد الصوتي
- زر نسخ السكريبت
- زر "توليد صوت السكريبت" → يولّد ملف صوتي واحد للسكريبت كاملاً كتعليق صوتي للفيديو

**القسم ج — البرومبتات المُرسَلة (قابل للطي):**
- يعرض تعليمات أسلوب الصوت الحالية
- يعرض البرومبت النظامي لتوليد المحتوى

## الإعدادات ⚙️

| الإعداد | الوصف |
|---------|-------|
| مفتاح Gemini API | مطلوب لجميع ميزات AI |
| موديل TTS | `gemini-2.5-flash-preview-tts` (سريع) أو `gemini-2.5-pro-preview-tts` (جودة أعلى) |
| الصوت | اختر من 30+ صوت Gemini (Kore، Charon، Puck...) |
| تعليمات أسلوب الصوت | نص بالإنجليزية يُرسَل قبل كل نص TTS لتوجيه نبرة الصوت |
| موديل توليد المحتوى | `gemini-2.5-flash` أو `gemini-2.5-pro` |
| البرومبت النظامي | تعليمات توليد نصوص الشرائح — قابل للتخصيص حسب قناتك |

## ميزات الرندر

- دقة **1920×1080** بترميز H.264/AAC
- **Turbo Mode:** تسريع الرندر بزيادة التوازي وتقليل جودة JPEG مؤقتاً
- خادم وسائط محلي مؤقت أثناء الرندر لضمان وصول Remotion للملفات
- توليد الـ bundle عند أول رندر (يُخزَّن كـ cache)

## pipeline توليد الصوت

```
نص الشريحة / السكريبت
       ↓
Gemini TTS (مع تعليمات الأسلوب)
       ↓
PCM → WAV (16-bit، 24kHz)
       ↓
يُحفظ في: %APPDATA%\...\voiceovers\
```

## pipeline توليد المحتوى (محتوى tab)

```
موضوع / مقالة
       ↓
Gemini (generateContent) → JSON: slides + fullScript
       ↓
مراجعة voiceoverText: قطع عند 18 كلمة
       ↓
pass ثانٍ: إعادة صياغة النصوص الطويلة بشكل طبيعي
       ↓
عرض السكريبت القابلة للتعديل
```

## إضافة أنماط نص جديدة

1. أنشئ ملف `src/remotion/text-animations/presets/MyNewText.tsx`
2. أضف الكومبوننت في `TextAnimationRenderer.tsx` (import + case)
3. أضف النوع في `types.ts` تحت `TextAnimationPreset`
4. أضف الخيار في `ANIMATION_PRESETS` بـ `app.js`
5. أعد بناء الـ preview player: `npm run desktop:v2:preview`

## أوامر البناء

```bash
npm run desktop:v2          # تشغيل التطبيق (dev mode)
npm run desktop:v2:preview  # إعادة بناء preview player (بعد تعديل TypeScript)
npm run desktop:v2:bundle   # إعادة بناء Remotion bundle (للإنتاج)
npm run desktop:v2:clean    # حذف cache البناء
npm run desktop:v2:build    # بناء كامل للتوزيع
```
