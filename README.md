# Infographic Video Generator

أداة داخلية مبنية بتقنيات (Next.js & Remotion) لفريق المونتاج، تهدف إلى إنتاج فيديوهات إنفوجرافيك سريعة بجودة عالية (1920x1080) بدون الحاجة لفتح برامج المونتاج المعقدة يومياً.

## هيكل المشروع والأصول (Assets)

لكي يعمل المشروع بشكل مثالي ويعرض جميع الخيارات، يجب وضع الملفات الثابتة في الاماكن التالية:

- **الأطارات الشفافة (Overlays):**
  قم بوضع ملفات الـ `.mov` (ذات الشفافية) داخل المسار: `public/assets/overlays/`
- **المقاطع الصوتية (Music):**
  قم بوضع ملفات الـ `.mp3` داخل المسار: `public/assets/music/`
- **شاشة الخاتمة (End Page):**
  قم بوضع ملف الفيديو `.mp4` (الذي يمثل الشعار والنهاية) داخل المسار: `public/assets/endpage/`

## متطلبات التشغيل
لتشغيل المشروع محلياً وبشكل محمول بالكامل (Portable Layout):

1. تأكد من تثبيت `Node.js` (نسخة حديثة LTS).
2. قم بتحميل `ffmpeg.exe` من موقع FFmpeg أو باستخدام نسخة جاهزة لويندوز، وضع الملف التنفيذي `ffmpeg.exe` داخل مجلد `bin/` في جذر المشروع. 
  *(المسار يجب أن يكون `bin/ffmpeg.exe`). إذا تعذر ذلك سيحاول Remotion تنزيله تلقائياً.*

## أوامر التشغيل (Run Instructions)

1. **تثبيت الحزم (لأول مرة فقط):**
   ```cmd
   npm install
   ```
2. **التشغيل للعمل اليومي (Development):**
   ```cmd
   npm run dev
   ```
   ثم افتح المتصفح على `http://localhost:3000`. يمكن للعاملين استخدام الواجهة من هناك وتصدير الفيديوهات.
3. **أين تجد الفيديو الناتج؟**
   جميع الفيديوهات المنتجة (الرندر النهائي) سيتم حفظها محلياً داخل مجلد `output/` باسم `Video_XXXX.mp4`. يمكن أيضاً الضغط على رابط التحميل الموجود في الواجهة بعد انتهاء الرندر.

## ملاحظات للتوسعة المستقبلية (Future Expansion)

1. **إضافة انتقال جديد (Transition):**
   يمكن التعديل على `src/remotion/Transitions.tsx` وإضافة تأثيرات جديدة برمجياً باستخدام `interpolate()`.
2. **إضافة نوع نص جديد:**
   يمكن التعديل على `src/remotion/Slide.tsx` داخل `Subtitle` كومبوننت لتعديل الألوان و الأيقونات، الخطوط، والسرعة.
3. **تغيير الموسيقى أو الأطارات في الواجهة:**
   افتح `src/app/page.tsx` وقم بتعديل عناصر الـ `<select>` لإضافة الخيارات التي توافق أسماء الملفات التي وضعتها في مجلد `assets`.
